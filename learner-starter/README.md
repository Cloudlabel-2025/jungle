# Alumni Connect learner starter

This is a separate, deliberately unsolved MERN workspace. It does not replace or import the CODEWILD platform. The platform's frozen Sprint 1 and Sprint 2 manifests are the task source; CC supplies approved Curriculum resources and later sprint content.

Use Node 22. Run `npm install`, then `npm run dev` for the frontend and `npm run server` in another terminal for the API scaffold. Copy `.env.example` to `.env` and supply your own learner database when you implement persistence. `npm test` checks only scaffold startup; `npm run build` checks the frontend bundle. Neither command proves sprint acceptance.

The API intentionally returns HTTP 501 until you implement assigned work. Add the real schema, routes, validation, authentication, authorization, pages, dependency handovers, and meaningful positive/negative tests from your approved task cards. No completed login, directory, search, profiles or CRUD solutions are included. MongoDB is a dependency for your implementation, not a bundled service. Keep learner secrets outside version control. Record your own SDLC reasoning and evidence in CODEWILD.
