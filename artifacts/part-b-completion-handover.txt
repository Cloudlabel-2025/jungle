Implemented in this change
1. Full Thursday export data: linked team manifest and per-Gamer dossiers; thirteen approved criterion rows/maxima/evidence; explicit NOT_ASSESSED; source/staging references; known-defect dispositions; actual prior acceptance evidence; attributed task references; role history; approved observations; approved Week 1 baseline/readiness where recorded. Aliases and allowlisted fields exclude private coaching notes and account contacts. Source sanitisation confirmation is mandatory; URLs with credentials, queries or fragments are refused. Missing code is NOT_ASSESSABLE and cannot produce imported code findings.
2. Human question governance: exactly Q1 common, Q2 personalised and Q3 reasoning, mapped criteria, answer expectations, evidence and equivalent alternates. Assigned MC review creates a new version, CC approves that version, and passing defence evidence names it. Stale edits revoke current approval, invalidate prior passing witness outcomes and remove gates 5–7. Historical versions/reasons remain auditable. AI never writes final marks or acceptance.
3. Arena assessor access: the five qualified reviewers retain their existing MC/CC role families. A cross-team MC assessor sees only their assigned persona candidates/approved questions and may record that persona’s witnesses. No cross-team score or general task-board access is granted. CC retains independent final acceptance.
4. Optional Administrator's Chair: voluntary ten-minute bookings, authorised reviewers, overlap protection, Friday arena/sprint timing, mandatory demo+private-defence prerequisite, completed session, five individually evidenced points, explicit isolated environment/target/baseline/rollback and accepted-release protection. Bonus equals earned points, stays outside core and is recorded once. CC validates the booked assessor’s findings. The platform records evidence; technical operators execute and verify actual code changes.
5. Award evidence: frozen categories preserved, one criterion honour per Gamer, highest-marks specials computed from their original two approved criteria across the cohort, tied highest candidates preserved, explicit reasoned overrides with truthful announcement labels. Showcase selection is one evidenced finalist per persona and has no scoring effect.
6. Reports: CC approves criterion/evidence profiles; unknown criteria remain NOT_ASSESSED. Private text-escaped print drafts include thirteen scores, four dimensions, separate bonuses, available baseline/readiness, five-sprint progression, contributions, evidenced strengths/development actions, persona/defence and verification footer. Certificate uses the exact frozen body, recipient, dates, stable unique ID and signature labels without scores. Staff print/save locally, verify PDF layout and upload through the existing private store. MC review explicitly confirms two pages, wording and evidence; CC issues after approved core, witness and Key 5. Authorised reopen/core corrections revoke old learner access and require review/reissue.

How to operate
- Programme setup: load the existing frozen content and actual cleared roster, resources and schedules. Existing records have no invented approvals.
- Programme Sprint Work / Client acceptance: use the downloadable JSON formats to export safe Thursday evidence, import AI advisory, submit MC question review, approve as CC, publish the five-arena plan and book optional sessions.
- Assigned persona arena: human assessor reads only the authorised candidate's questions and records private outcome/evidence. Keep candidates who are waiting out of graded question sessions.
- Private Capability Passport and certificate: approve evidence profile as CC, prepare private HTML print drafts, save verified PDFs locally, upload, review as assigned MC and issue as CC. Generated files are DRAFTS until human verification and issuance.
- Awards: select the original category, record evidence/reason and decision; use override=true only for an intentional non-highest special selection. The stored announcement distinguishes an override from a numerical highest scorer.
