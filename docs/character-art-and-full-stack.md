# Character cast and full-stack projects

The cast has five identities: Blaze (Zayn/Zara), Glitch (Jett/Juno), Shade (Nyx/Nia), Pulse (Kai/Kira), Rune (Riven/Rhea). Each has male and female portrait versions with identical gameplay. Portraits were generated and then revised using the built-in image_gen tool. Final optimized assets live in `public/images/characters/`; generation sources and individual appearance/outfit prompts are recorded in `character-image-sources.json`. Earlier sources remain in `character-image-sources-v1.json`.

Final edit prompt template, with CHARACTER, VARIANT, APPEARANCE and OUTFIT substituted from the source manifest:

> Edit this existing character portrait. Keep its premium highly cartoonish 3D animated-film/game style, young-adult age 22-25, confident friendly personality, large expressive eyes, slightly oversized head, chunky streetwear, square upper-body framing, jungle backdrop, cinematic soft light and overall accessory identity. Character CHARACTER, VARIANT version. Redesign the character's ethnicity, complexion and hair as: APPEARANCE. Outfit colour identity: OUTFIT. Make the specified complexion clearly visible and accurate in neutral face lighting; avoid washing brown or dark skin out with excessive yellow lighting. This cast must have meaningful visible skin-tone and ethnic diversity rather than the same light face recoloured. Natural respectful stylised features, no ethnic costume, no stereotypes. Retain youthful playful 3D cartoon proportions, no photorealism. No text, logos or watermark.

## Curriculum and compatibility

New built-in level attempts assign five distinct features to the five character holders. Each feature has frontend, backend, database, testing, and deployment/integration tasks (25 total). Task IDs remain unique without deleting or rebuilding existing task indexes. Character variants do not alter assignments, stars, deadlines or rewards.

Every task needs evidence and independent Guide review. Teams may submit the integrated project while task reviews are pending, but clearance requires all 25 approvals and every integrated check. Individual completion rewards are awarded once per player, using the rounded average of their five contribution scores and the existing star multiplier.

Started attempts retain their definition snapshots. Older unpinned built-in attempts resolve to the original five-role definition. Existing published custom levels remain unchanged until Centre Command explicitly creates and publishes a full-stack draft. The level workshop supports five features and 25 editable task definitions, image selection, recipient preview and publication.

Players can change the male/female version of their identity; characters held by teammates are unavailable in self-selection. Centre Command can swap identities. Existing task ownership stays pinned; a Guide can reassign a whole unapproved feature to a matching replacement. Approved feature tasks must be reopened before reassignment.
