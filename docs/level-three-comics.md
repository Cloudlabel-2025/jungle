# Level 3 comic artwork

These illustrations belong to the earlier Level 3 scene interface and are retained as artwork history. The current Signal Lab uses a circuit workbench and module tray instead of comic scenes. See `level-three-gameplay.md` for the current flow.

Generated using the built-in image-generation tool. The existing character at `public/images/pip/pip-guiding.webp` was supplied as Kiko's identity reference. The game keeps using the existing Kiko expression assets.

Final artwork lives in `public/images/level-three-comics/`: `nature-v1.webp`, `space-v1.webp`, `sports-v1.webp`, `transport-v3.webp`, `crew-login-v1.webp`, `flight-logs-v1.webp`, `crew-profile-v1.webp`, and `supply-request-v1.webp`.

Each source sheet is 1536 × 1024, with four 768 × 512 scenes in reading order. The runtime displays two complete scenes per spread using a contain fit. Dialogue, scene numbers and clue text are HTML below the artwork. The artwork does not replace a player's pinned scenario, draft, timer or submission.

## Prompt set

Shared specification: hand-inked olive-and-gold expedition comic; exactly four equally sized panels without gutters, text or speech balloons. Two consistent college-age explorers. Kiko must retain the round olive body, cream face rim, glossy black face, green eyes, two circular green rotor pods, antenna, articulated arms and utility pouch of the supplied reference. Screens and keyboards face the same reader; printed cards face their readers and show plain backs when viewed from the opposite side. Hands have correct left/right anatomy and natural shoulder, elbow and wrist attachment.

| Sheet | Four scenes requested |
|---|---|
| Nature | New flowers and butterfly increase; unusually warm observation day; comparable garden patches; cautious explanation. |
| Space | Recurring light at dusk; cloudy-night sighting; camera-clock check; another observation. |
| Sports | New training routine; weaker opponents; two missing reports; fair comparison. |
| Transport | Route survey; quiet off-peak journey; rush-hour congestion; comparable survey periods. |
| Crew Login | Browser login; server validation and permissions; account record; confirmed browser response. |
| Search Flight Logs | Browser search; checked request; matching database records; displayed response. |
| Update Crew Profile | Edit own profile; ownership check; update own record; confirmed response. |
| Supply Request | Request supplies; validate and authorise; store request; acknowledgement rather than a delivery guarantee. |

Targeted revisions preserved Kiko's supplied design, turned the flight-record cards toward their readers, and changed laptop scenes to over-the-shoulder views. The final Transport revision corrects map orientation, removes the detached second hand and uses one connected, camera-near left forearm and relaxed hand in every panel. The far arm stays occluded consistently; pointing and chin-support poses are removed.

Scenario-to-comic matching uses frozen brief text, variant identity and the supplied technical component cards. Edited or historical scenarios fall back to their original briefing rather than receiving unrelated comic clues.
